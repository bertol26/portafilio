# Portafolio de Bertol Franco

Portafolio web estático desarrollado con HTML, CSS y JavaScript nativo. No requiere framework, dependencias ni proceso de compilación.

## Ejecutar localmente

Abre `index.html` en un servidor estático. Por ejemplo, con Python:

```bash
python -m http.server 8000
```

Después visita `http://localhost:8000/`.

## Estructura

- `index.html`: estructura semántica y contenido de las secciones.
- `css/`: estilos base, secciones, componentes y ajustes responsive.
- `js/content.js`: datos de tecnologías, proyectos y formación.
- `js/main.js`: renderizado, navegación, animaciones, partículas y formulario.
- `img/` y `fonts/`: recursos visuales y tipografía local.

El formulario prepara un mensaje en la aplicación de correo del visitante. No envía datos a un servidor.
